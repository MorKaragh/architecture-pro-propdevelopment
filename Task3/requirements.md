# Требования к функциональности умного дома

## Описание функциональности

#### Интеллектуальный домофон. 

Включает функции классического видеодомофона — открытие по звонку. Также есть возможность распознавать пользователей по биометрии (по лицу) и автоматически открывать дверь, если им разрешён доступ в дом.

#### Интеллектуальный шлагбаум.

Включает функции классического управления шлагбаумом и автоматически открывает доступ, если распознаёт номера автомобилей, которым въезд разрешён.

## Описание данных

В систему добавляются следующие данные

| Данные | Классификация |
| ------ | ------------- |
| Идентификатор домохозяйств | Конфиденциальные | 
| Биометрия пользователей | Конфиденциальные, персональные |
| Автомобильные номера допущенных ТС | Конфиденциальные |
| Credentials для сервисов партнёра | Секретные |
| История использования, логи, телеметрия функциональности | Внутренние |
