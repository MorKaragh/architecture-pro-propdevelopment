| Роль  | Права роли | Группы пользователей |
| --- | --- | --- |
| cluster-admin | Полный доступ ко всем ресурсам кластера: создание, чтение, обновление, удаление всех ресурсов во всех namespace, просмотр секретов, управление RBAC, доступ к узлам кластера | DevOps-инженеры, Специалист по ИБ (привилегированная группа) |
| namespace-admin | Полный доступ к ресурсам в конкретном namespace: создание, чтение, обновление, удаление всех ресурсов в назначенном namespace, просмотр секретов в namespace | Владельцы продуктов (Product Owners) по доменам (Группа сервисов для продаж, Группа сервисов ЖКУ, Финансы, Дата) |
| developer | Доступ на создание, чтение, обновление, удаление стандартных ресурсов (Deployment, Service, ConfigMap, Ingress) в назначенном namespace. Нет доступа к секретам и RBAC | Разработчики продуктовых команд |
| operations-engineer | Чтение всех ресурсов кластера, просмотр секретов во всех namespace, чтение логов и метрик, доступ к событиям кластера. Нет прав на изменение ресурсов | Инженеры по эксплуатации (привилегированная группа) |
| viewer | Только чтение всех ресурсов кластера (кроме секретов). Доступ к просмотру Deployment, Service, Pod, ConfigMap, Ingress и других ресурсов. Нет прав на создание, обновление, удаление | Бизнес-аналитики, Аналитики BI, Менеджеры |
| security-auditor | Чтение всех ресурсов кластера, просмотр секретов, чтение событий безопасности, доступ к аудит-логам. Нет прав на изменение ресурсов | Специалист по ИБ (привилегированная группа) |
